# Review Queue — rows 35–55

> Source: User Stories — section **Review Queue** (header row 35).

## Teacher

| Row | Story | Priority |
|---|---|---|
| 36 | Teacher can view a list of content needing review with Content, Rule broken, Why it was stopped, Learner, Product, Where it is, Status, Waiting time so that they can clear it from one place | P1 |
| 37 | Teacher can view content needing review together with the surrounding conversation so that a borderline item can be judged in context | P1 |
| 38 | Teacher can view a learner's moderation history alongside their content so that repeat behaviour is visible | P1 |
| 39 | Teacher can view the edit history of content so that changes made after it was held are visible | P1 |
| 40 | Teacher can approve content so that it becomes visible to learners | P1 |
| 41 | Teacher can remove content so that it stops being visible to learners | P1 |
| 42 | Teacher can restore removed content so that a wrong decision can be undone | P1 |
| 43 | Teacher can view how much content is waiting for review so that the queue is not forgotten | P1 |
| 44 | Teacher can view how long the oldest content has waited so that takedown obligations are met | P1 |
| 45 | Teacher can view content that was published without a check so that failures can be caught up on | P1 |
| 46 | Teacher can mark decided content as an example so that future checks match the academy's own decisions | P2 |
| 47 | Teacher can restrict a learner so that their content is reviewed before becoming visible | P1 |
| 48 | Teacher can ban a learner from a single product so that they lose access where they caused trouble and keep the rest of the academy | P1 |
| 49 | Teacher can ban a learner from the academy so that they can no longer post in any product | P1 |
| 50 | Teacher can remove a banned learner's existing content within the ban's scope so that one action clears what they posted there | P1 |
