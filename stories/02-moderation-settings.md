# Moderation Settings — rows 1–15

> Source: User Stories — section **Moderation Settings** (header row 1).

| Row | Story | Priority |
|---|---|---|
| 2 | Teacher can switch moderation on or off for their academy so that they control whether content is checked | P1 |
| 3 | Teacher can switch moderation on or off for each forum a learner writes — Product discussions, Community, Feeds, Newsfeed — so that they can start with one place and widen later | P1 |
| 4 | Teacher can set the content review mode for their academy — Review first, Publish first — so that they choose between nothing bad ever appearing and conversation never waiting | P1 |
| 5 | Teacher can set the moderation mode for their academy — Autopilot, Copilot, AI disabled — so that they control how much the AI decides alone | P1 |
| 6 | Teacher can describe their academy with Description\*, Learner age group\*, Tone of conversation\* so that content is judged in the right context. Learner age group: Under 18, Adults, Mixed. Tone of conversation: Casual, Professional | P1 |
| 7 | Teacher can set how much removed content triggers a restriction with Number of removals\* so that repeat behaviour is handled without manual checking | P1 |
| 8 | Teacher can set how much repeated content within a period counts as spam with Number of posts\*, Within how long\* so that flooding is stopped | P2 |
| 9 | Teacher can hold a new learner's first posts with Number of first posts to hold\* so that academies with free signup are protected | P3 |
| 10 | Teacher can add an exception for a product with Product\*, Content review mode, Moderation mode so that one product can be stricter or looser than the academy | P2 |
| 11 | Teacher can switch a rule off for a product within an exception so that a rule which does not fit that product stops being enforced there | P2 |
| 12 | Teacher can switch a rule back on for a product so that it follows the academy again | P2 |
| 13 | Teacher can view which rules are in force for a product so that they can see what an exception changed | P2 |
| 14 | Teacher can view the exceptions list with Product, What is different, Set on so that a setting made months ago is not forgotten | P2 |
| 15 | Teacher can remove an exception so that the product follows the academy settings again | P2 |
