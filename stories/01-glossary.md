# User types · Glossary additions

> Source: User Stories — header and "Glossary additions".

**User types:** Teacher / Admin · Teaching Assistant · Learner

## Glossary additions

| Term | Definition |
|---|---|
| **Where it runs** | The four places a learner writes — Product discussions, Community, Feeds, Newsfeed. Each is switched on or off. Product discussions covers Course, Bundle, Batch, Mock Test, Test Series, Ebook, Webinar, Free Resource, Podcast and Custom products |
| **Content review mode** | When the check happens — Review first, content is held until checked, or Publish first, content goes live and comes down if it breaks a rule. Set once for the academy. Default is Review first |
| **Moderation mode** | How much the AI decides alone — Autopilot, Copilot or AI disabled. Set once for the academy |
| **Autopilot** | The rule's action is applied automatically |
| **Copilot** | Nothing is stopped automatically; flagged content waits for a person |
| **AI disabled** | The AI never runs. Blocked words and learner reports only |
| **Exception** | One product set differently from the academy — its content review mode, its moderation mode, and which rules apply. Added in Settings, listed there, removable. Rules themselves are always written in Rules, never inside an exception |
| **Tone of conversation** | How learners talk to each other in this academy — Casual or Professional. Banter that is normal in one is not in the other |
| **Rule** | A community rule written by the academy in plain language. Draft until published |
| **Blocked word** | A word or web address inside a rule. Stops content on sight, with no AI check |
| **Blocked** | Content that was never created |
| **Held** | Content that exists but is not visible to anyone except its author |
| **Restriction** | A learner whose content is reviewed before becoming visible, across every product. Not a ban |
| **Ban** | A learner blocked from posting — in one product, or across the whole academy. The Teacher chooses which. Their course enrolment is untouched either way |
| **Wrong-flag rate** | Content a rule stopped that a Teacher then approved, as a percentage |

> ⚠ "Set once for the academy" (content review mode, moderation mode) differs from the spec and HLD, which also
> set both per content area. See [`../open-items.md`](../open-items.md) C2.
