# Moderation Reports — rows 60–68

> Source: User Stories — section **Moderation Reports** (header row 60), plus the two notes that follow the
> stories table.

| Row | Story | Priority |
|---|---|---|
| 61 | Teacher can view a Moderation summary with Where it runs, Content checked, Blocked before publishing, Held for review, Approved after review, Removed, Reported by learners, Waiting for review, Longest waiting, Published without a check so that they can see at a glance whether moderation is keeping up | P1 |
| 62 | Teacher can view a Rule performance report with Rule, Times this rule stopped content, Approved anyway by a Teacher, Removed, Wrong-flag rate so that they can see which rules are working and which are too strict | P1 |

## Notes that follow the stories table

**Wrong-flag rate** is content a rule stopped that a Teacher then approved, as a percentage. It is the number that
says a rule is too strict.

**Longest waiting** is the one to watch — Indian IT rules give each academy 36 hours to take unlawful content down,
and that clock runs against this number.
