# Rule performance

> Source: Spec — "Rule performance".

Per rule, over **7 or 30 days**: times fired, times a Teacher approved anyway, wrong-flag rate.

Approved high → too strict. Removed high → missing things. Never fires → too vague.

**Test before publishing** — type a sample post, see whether the rule catches it.

**Learn from decisions** — mark a decided item as an example, and it sharpens future checks for that academy
only.
