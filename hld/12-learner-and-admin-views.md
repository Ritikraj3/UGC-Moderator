# §12 What the learner sees, and what the admin sees

> Source: HLD §12.

## The learner sees the rule — never generated text

> **Can't be published — Rule 6: No spam**
>
> No promotions, advertising or selling of any kind.
>
> Edit your post and try again.

The name and description are the academy's own words. No machine-written text ever reaches a learner, there is no
fallback wording to maintain, and translation solves itself.

Under review first they see *waiting for review* first, then this. Under publish first they see their post go up,
then a note if it comes down.

## The admin sees the generated reason, in the queue row

> Rule 6 — links to an outside site offering a discount, which reads as advertising

## Self-harm

Self-harm is different again. ai-server returns only the rule id; Rails shows its own fixed message and the
helpline, and never names the rule.
